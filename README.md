# Smart Choice Guide

Free static website starter for GitHub Pages.

## Before publishing
1. Replace `hello@example.com` in `contact.html`.
2. Add your real TikTok and YouTube URLs.
3. Replace placeholder product links with your approved affiliate links.
4. Customize Privacy Policy and Terms for your actual business and target markets.
5. Add original, researched articles before applying to an affiliate program.

## GitHub Pages
Create a new public repository named `smart-choice-guide`, upload these files, then enable Pages from the repository settings using the `main` branch and `/root`.
